# Помощник по нормативке

Учебный справочник команды «Вега», УВИ-271. Это гипотеза Г1: десять карточек с ответом и пунктом нормативного документа. Языковой модели нет. Журнал обращений в сайт не загружается.

Папка `src` — исходные материалы. Программа их не переписывает.

## Чего в программе нет

- расчёта тарифа, провозной платы и маршрута;
- текста претензии и юридического заключения;
- связи с системами перевозчика;
- отправки вопросов сотрудников наружу;
- эталона из 50 вопросов. Его заполняют после того, как карточки заморожены, и не используют для подбора ключевых слов.

## Как запустить

Нужен Python 3.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 scripts/baseline.py
python3 app/app.py
```

На Windows виртуальное окружение включается так: `.venv\Scripts\activate`.

Откройте в браузере http://127.0.0.1:5000

Сервер слушает только этот компьютер.

## Карточки

Файл `data/cards.csv`. Все десять карточек сейчас в статусе «черновик»: ответ набран по открытым текстам, но пункт команда ещё не сверила с официальной публикацией.

Сотрудник видит только статус «проверено». Черновик и статус «устарело» в поиске скрыты. Если подходящей проверенной карточки нет, страница так и пишет и не придумывает ответ.

Чтобы карточка появилась в поиске:

1. Откройте «Правка карточек».
2. Сверьте пункт с официальным текстом. Пункт и ссылку меняют в `data/cards.csv`, затем нажимают «Перечитать CSV».
3. Уберите из текста пометку, что это черновик.
4. Поставьте статус «проверено», укажите, кто проверил, и сохраните.

Страница правки без пароля. Её не нужно открывать в общей сети.

Десять тем — это вопросы с наибольшим временем в журнале за 2025 год. Список печатает `python3 scripts/baseline.py`: 14 000 обращений, 994 054 минуты, топ-10 — 7 032 обращения и 50,85% всего времени. Номера сотрудников скрипт не выводит.

## Поиск

Слова запроса ищутся в формулировке вопроса, категории и ключевых словах. Регистр и буква «ё» не важны. Слово короче трёх букв пропускается. «срок» находится и внутри слова «сроки». Если несколько карточек набрали одинаково больше всех, показываются все они. Текст ответа в поиск не входит.

Каталог Г0 — те же темы, но без ответа и без условий. Только документ и пункт. Им засекают время поиска по ссылке.

## Как посчитать метрики

Протокол: `data/protocol.csv`. Сейчас в нём только заголовок.

Столбцы:

- `номер` — номер проверочного вопроса;
- `вариант` — `Г0` или `Г1` (латинские `G0` и `G1` тоже понимаются);
- `секунды` — время ответа;
- `карточка` — какую карточку открыли, можно оставить пустым;
- `ответ` — что ответили;
- `пункт` — какой пункт назвали;
- `верно` — `да`, только если верны и смысл ответа, и пункт;
- `причина` — для неверного пункта пишите ровно `неверный пункт`.

Запуск:

```bash
python3 scripts/metrics.py
```

Скрипт печатает долю верных ответов, число неверных пунктов и насколько среднее время успешного ответа Г1 быстрее Г0. В записке по решению порог скорости — не меньше 20%, порог верности — не меньше 45 из 50, неверных пунктов — ноль. Сам скрипт порог не «проставляет»: он только считает то, что записано в протоколе.

Если Excel на русской Windows разобьёт столбцы криво, откройте файл через «Данные → Из текста» и укажите запятую и кодировку UTF-8.
