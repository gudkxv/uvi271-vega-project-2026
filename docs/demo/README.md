# Как выглядит справочник

Снимки с проверки. В репозитории все карточки снова в статусе «черновик». На снимке карточки статус «проверено» стоял только на время проверки и был возвращён обратно.

- `home_empty.png` — сотрудник ещё не видит карточек.
- `g0_links.png` — каталог Г0: документ и пункт, без готового ответа.
- `search_hit.png` — поиск «отправления вагона» нашёл карточку.
- `card_verified.png` — открытая карточка.
- `search_miss.png` — незнакомый запрос не получает выдуманный ответ.
- `search_card_and_status_change.mp4` — тот же проход целиком.
