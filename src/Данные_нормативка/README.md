# Помощник по нормативке: материалы

Здесь нет готовой базы документов: нормативные документы открытые, собрать их часть вашей работы. Зато есть то, чего в открытом доступе нет: какие вопросы реально задают сотрудники и сколько времени уходит на ответы.

## Файлы

| Файл | Что это |
|---|---|
| questions.csv | 70 типовых вопросов сотрудников по 10 категориям. Ответов нет |
| requests_log.csv | Журнал обращений за 2025 год, 14 тысяч записей: кто искал ответ, на какой вопрос, сколько потратил времени, нашёл ли |

## requests_log.csv

| Поле | Описание |
|---|---|
| request_id | Номер обращения |
| ts | Когда начали искать ответ |
| department | Отдел сотрудника |
| employee_id | Сотрудник |
| question_id | Вопрос из questions.csv |
| minutes_spent | Сколько минут ушло на поиск ответа |
| source_used | Где в итоге искали |
| answer_found | Нашли ответ или нет |
| escalated_to_lawyer | Пришлось ли идти к юристу |
| answer_later_found_wrong | Ответ нашли, но позже он оказался неверным |

Данные синтетические, но устроены так же, как реальная статистика обращений.

## Документы, с которых стоит начать

Берите официальные тексты в действующей редакции (pravo.gov.ru, КонсультантПлюс, Гарант, сайт перевозчика):

- Устав железнодорожного транспорта Российской Федерации (Федеральный закон № 18-ФЗ);
- правила перевозок грузов железнодорожным транспортом, утверждённые Минтрансом России;
- правила исчисления сроков доставки грузов железнодорожным транспортом;
- Прейскурант № 10-01 «Тарифы на перевозки грузов и услуги инфраструктуры»;
- правила перевозок опасных грузов по железным дорогам.

Какие именно редакции и приказы действуют сейчас, выясните сами: это тоже часть задачи.

## Что нужно сделать в первую очередь

1. Посчитать по журналу, сколько времени в год уходит на поиск ответов и где больнее всего. Это ваша точка отсчёта: с ней вы будете сравнивать результат.
2. Собрать эталонный набор: не меньше 50 вопросов из questions.csv с правильными ответами и ссылкой на конкретный пункт документа. Без него качество помощника не измерить.
